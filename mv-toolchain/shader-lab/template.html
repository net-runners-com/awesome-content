Shader Lab

雨ガラス → ディゾルブ → ポストプロセスの順に、UnityのVFXでよく見る表現をGLSLで再現。スライダーはそのままuniform。

Rain Glass

縦長セルに1滴ずつ落下＋軌跡。滴の法線で背景（手続き玉ボケ）を屈折させ、滴の外側は曇らせる。Heartfelt方式。

Dissolve

3Dノイズ < 閾値 で discard（= Unity の Alpha Clip Threshold）。閾値付近の帯を Emission で発光。

Post Processing

UnrealBloomPass → 自作パス（色収差・ビネット・グレイン）→ OutputPass。
